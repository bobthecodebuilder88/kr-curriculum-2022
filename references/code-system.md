# 2022 개정 교육과정 코드 체계

성취기준 코드를 읽고 쓰는 법과, 접두어→과목명 전체 대응표다.
표는 `index/subjects.json`에서 기계 생성했다 — 손으로 고치지 말고 그쪽을 고쳐라.

## 코드 구조

2단 코드 — 대부분의 성취기준:

```
[9수01-01]
 │ │  │  └ 일련번호(01)
 │ │  └─── 영역 번호(01)
 │ └────── 과목 약어(수 = 수학)
 └──────── 학년군 접두(9 = 중1-3)
```

3단 코드 — 고등학교 공통 과목과 일부 선택 과목:

```
[10공수1-01-01]
 │   │     │  └ 일련번호
 │   │     └─── 영역 번호
 │   └───────── 과목 약어(공수1 = 공통수학1)
 └───────────── 학년군 접두(10 = 고 공통)
```

## 학년군 접두

| 접두 | 대상 | 데이터의 `grade_band` |
|---|---|---|
| `2` | 초등학교 1~2학년 | 초1-2 |
| `4` | 초등학교 3~4학년 | 초3-4 |
| `6` | 초등학교 5~6학년 | 초5-6 |
| `9` | 중학교 1~3학년 | 중1-3 |
| `10` | 고등학교 공통 과목 | 고(공통) |
| `12` | 고등학교 선택 과목 | 고(선택) |

## 표기 변형 (실재하는 것들)

- 로마숫자 꼬리: `12영Ⅰ-01-01`, `12미적Ⅱ-01-01` — 약어 자체에 Ⅰ·Ⅱ가 붙는다.
- 괄호 약어: `9사(일사)01-01`(일반사회), `9사(지리)01-01`(지리) — 중학교 사회.
- 숫자 꼬리: `10공국1`, `12체육2`, `12스생1` — 약어 끝의 숫자는 과목 번호이지 영역이 아니다.

## 같은 코드가 두 과목에 있는 자리

아래 표에서 `(접두+약어)`가 같은데 교과가 다른 행이 두 쌍 있다 — `12스문`(체육 「스포츠 문화」 /
제2외국어 「스페인어권 문화」)와 `12심독`(영어 「심화 영어 독해와 작문」 / 제2외국어 「심화 독일어」).
성취기준의 고유키는 `(교과, 코드)`이지 코드 단독이 아니다. SKILL.md 절대 규칙 3 참조.
